# Claude Code Extension

- Preserve pi-claude-bridge 0.9.3 attribution (Eli Dickinson; originally based on Prateek Sunal's claude-agent-sdk-pi) in LICENSE, NOTICE, and the root NOTICE. The vendored baseline is commit `874fa7c2678456336f23b64e784e2057e608d83e`.
- Keep upstream tabs and double quotes in `src/bridge/` so upstream changes remain diffable. Felan-owned files use two spaces and single quotes.
- Import Pi APIs only through `@felan-ai/agent-core`.
- This is a host-only I/O exception: the Agent SDK spawns Claude Code and owns files under `CLAUDE_CONFIG_DIR`; `cc-session-io` reads and writes Claude Code session JSONL; bridge debug and diagnostics logs use the activation `agentDir` (with explicit debug environment overrides). Keep other host operations behind `AgentRuntime`.
- Never add Anthropic or MCP packages to dependency fields. Load the managed SDK through `src/sdk/runtime.ts`; keep its minimal boundary types hand-written rather than copying proprietary declarations. Installation requires explicit user approval and never runs during activation or a model tool call.
- `src/bridge/` retains upstream's checked non-strict TypeScript settings: strict null checking adds assertions around state-machine invariants without proving them. Package configuration disables `strict`, `noUncheckedIndexedAccess`, and `exactOptionalPropertyTypes`, retains `verbatimModuleSyntax`, and enables upstream's unused-code, fallthrough, and return checks. Preserve state-machine behavior with tests.
- Keep `__test` hooks and the query override seam available for offline upstream test parity. Tests must inject the SDK and must not spawn Claude Code or use real user storage.
- When changing the managed SDK or peer pins in `src/managed/index.ts`, regenerate `src/managed/agent-sdk-package-lock.json` in a fresh temporary directory outside the workspace, without `node_modules`. Write a `package.json` whose `dependencies` exactly match all four updated pins, then run `npm install --package-lock-only --ignore-scripts --no-audit --no-fund --registry=https://registry.npmjs.org` with Node.js 22.20.0. Do not omit optional dependencies. Review the complete lockfile diff: lockfile v3, exact root pins, integrity and HTTPS npm-registry URLs for every non-root entry, and all eight SDK platform packages at the SDK version. Copy the reviewed lockfile into `src/managed/`, remove the temporary directory, and update the managed tests if the reviewed dependency count changes. Run build, type-check, tests, and a pack dry-run to verify that `dist/managed/agent-sdk-package-lock.json` ships. Runtime installation must use this committed lockfile with `npm ci`, never resolve dependencies afresh.
